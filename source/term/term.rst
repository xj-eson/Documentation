**术语库**
=================

1. 获取领域
-----------

**请求地址**

::

   GET /terms/get-domains


**返回值**

============= ====== ==========================================
属性          类型   说明
============= ====== ==========================================
id            long   领域id
parent_id     int    父级领域id
name          string 领域名称
childs        array  子领域集合，字段相同
============= ====== ==========================================

**返回数据示例**

.. code:: json

    [
        {
            "id": "1",
            "parent_id": "0",
            "name": "电力名词",
            "childs": [
                {
                    "id": "3",
                    "parent_id": "0",
                    "name": "电力名词子类",
                    "childs": []
                }
            ]
        },
        {
            "id": "2",
            "parent_id": "0",
            "name": "金融与银行词典",
            "childs": []
        }
    ]
    
2. 创建领域
-----------

**请求地址**

::

   POST /terms/create-domain

**请求参数**

============== ====== ====== ==== ========
属性           类型   默认值 必填  说明
============== ====== ====== ==== ========
parent_id      int           是   父级id
name           string        是   领域名
============== ====== ====== ==== ========

**返回值**

====== ======================
类型   说明
====== ======================
int    新增领域id
====== ======================
   
3. 修改领域
-----------

**请求地址**

::

   POST /terms/update-domain

**请求参数**

============== ====== ====== ==== ========================
属性           类型   默认值 必填  说明
============== ====== ====== ==== ========================
id             int           是   id
name           string        是   领域名称
============== ====== ====== ==== ========================

4. 删除领域
-----------

**请求地址**

::

   POST /terms/delete-domain

**请求参数**

============== ====== ====== ==== ========================
属性           类型   默认值 必填  说明
============== ====== ====== ==== ========================
id             int           是   删除的领域id集合
============== ====== ====== ==== ========================

**请求示例**

.. code:: json

    {
        "id": 1
    }

5. 获取术语
-----------

**请求地址**

::

   POST /terms/get-term

**请求参数**

=================== ====== ====== ==== =============================================
属性                类型   默认值 必填  说明
=================== ====== ====== ==== =============================================
lib_id              int           是   领域id
search_text         string        否   搜索关键字
page_index          int           是   页码(从1开始)
page_size           int           是   每页数量
=================== ====== ====== ==== =============================================

**返回值**

=============== ======== ==================
属性            类型     说明
=============== ======== ==================
result          object   数据
total_count     int      总数量
=============== ======== ==================

*result的结构*

=================== ======== ============================================
属性                类型     说明
=================== ======== ============================================
id                  string   术语id
src_language_type   string   原文本语种( :doc:`../overview/LanguageType`)
tgt_language_type   string   目标语种( :doc:`../overview/LanguageType`)
src_language_name   string   原文本语种名
src_language_name   string   目标语种名
src_content         string   原文
tgt_content         string   译文
create_time         datetime 创建时间
update_time         datetime 修改时间
=================== ======== ============================================

**返回数据示例**

正常返回

.. code:: json
   
   {
        "result": [
            {
                "id": "1",
                "src_content": "hello",
                "tgt_content": "你好",
                "src_language_type": 10,
                "tgt_language_type": 0,
                "src_language_name": "英语",
                "tgt_language_name": "中文(简体)",
                "create_time": "2024-10-29T00:00:26+00:00",
                "update_time": "2024-10-29T00:00:26+00:00"
            }
        ],
        "total_count": 1
    }

6. 添加术语
-----------

**请求地址**

::

   POST /terms/create-term

**请求参数**

=================== ====== ====== ==== =============================================
属性                类型   默认值 必填  说明
=================== ====== ====== ==== =============================================
lib_id              int           是   领域id
src_language_type   string        是   原文本语种( :doc:`../overview/LanguageType`)
tgt_language_type   string        是   目标语种( :doc:`../overview/LanguageType`)
src_content         string        是   原文
tgt_content         string        是   译文
is_reverse          bool          是   是否双向添加
=================== ====== ====== ==== =============================================

=================== ====== ====== ==== =============================================
id                  int           是   术语id
src_language_type   string        是   原文本语种( :doc:`../overview/LanguageType`)
tgt_language_type   string        是   目标语种( :doc:`../overview/LanguageType`)
src_content         string        是   原文
tgt_content         string        是   译文
is_reverse          bool          是   是否双向修改
=================== ====== ====== ==== =============================================

6. 删除术语
-----------

**请求地址**

::

   POST /terms/delete-term

**请求参数**

============== ====== ====== ==== ========================
属性           类型   默认值 必填  说明
============== ====== ====== ==== ========================
ids            array         是   删除的领域id集合
============== ====== ====== ==== ========================

**请求示例**

.. code:: json

    {
        "ids": [
            1,2,3
        ]
    }
